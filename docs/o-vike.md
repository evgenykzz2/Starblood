# О вики

Это неофициальный фанатский справочник. Все права на произведения, персонажей и мир принадлежат автору — Роману Прокофьеву. Вики не содержит текстов книг: только пересказ фактов о мире и персонажах и короткие цитаты для иллюстрации.

## Как добавить иллюстрации персонажей

Картинки подставляются на страницы автоматически, править тексты не нужно.

1. Найдите адрес страницы персонажа. Например, у Сигурда это `personazhi/sigurd/` — значит, его имя файла `sigurd`.
2. **Главная иллюстрация:** положите файл `docs/assets/personazhi/sigurd.png` (подойдут также `.jpg` и `.webp`). Картинка появится справа от начала статьи.
3. **Галерея обликов:** создайте папку `docs/assets/personazhi/sigurd/` и положите туда картинки. Они выводятся по алфавиту имён файлов, а подпись берётся из имени без номера, например `03_В доспехе Небесного Ястреба.png`.
4. Закоммитьте файлы в ветку `main`. Через пару минут сайт пересоберётся сам.

## Как обновить вики

Тексты страниц собираются из базы знаний в репозитории [star-blood](https://github.com/evgenykzz2/star-blood) скриптом `tools/build_wiki.py`. Ручные страницы — главная, эта страница, «Обозначения и книги», карта и папка `docs/assets/` — при пересборке не перезаписываются.
