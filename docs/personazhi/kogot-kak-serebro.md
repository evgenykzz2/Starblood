# Коготь-как-Серебро

| | |
|---|---|
| **Имена** | Коготь-как-Серебро (Серебряный Коготь) |
| **Раса / Народ** | Народ Теней, септа Небесных Когтей; первый сын рикса Видящей-сквозь-Тьму, эрл-знаменосец → рикс септы |
| **Роль** | Враг-пленитель Сигурда (ЗК-3) → связан тайной Клятвой служить «небесному господину» (Белому Дьяволу) |
| **Книги** | ЗК-3, ЗК-6, ЗК-9; ТБ (Тени Пламени Подобного) |
| **Статус** | Жив; рикс Небесных Когтей, присягнул Пламени Подобному (ЗК-9) |

**Внешность:** высокий, гибкий копейщик-серебро, лицо изуродовано когтистой лапой, позже — отпечаток пылающей ладони Белого Дьявола (ЗК-3).
**Характер/речь:** горд, жаден до Славы, жесток, уважает силу; клянётся «Кровью Белого Дьявола». «Он дрался подобно Белому Дьяволу… и так и не дал мне победы» (ЗК-3).
**Биография.** ЗК-3: пленит и пытает Сигурда; побеждён голосом; посадил кукольника у винтокрыла. ЗК-6: новый рикс; выманивает Говорящую, свидетельствует; дарит Иллиумовый Страж-браслет, Сигурд возвращает ему тарн (гл. 17). ЗК-9: принимает Клятву Пламени Подобному, отпущен ждать знака (гл. 8).
**Связи:** мать — Видящая-сквозь-Тьму (рикс, духовидец; умерла по приказу «небесного господина» после закрытия Портала, ЗК-3, ЗК-6): «Лучше отдать мертвое железо, чем живую кровь»; старый товарищ Тростник-который-Поет убит голосом (ЗК-3).
