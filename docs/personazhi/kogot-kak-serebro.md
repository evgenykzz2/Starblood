# Коготь-как-Серебро

| | |
|---|---|
| **Имена** | Коготь-как-Серебро (Серебряный Коготь) |
| **Раса / Народ** | Народ Теней, септа Небесных Когтей; первый сын рикса Видящей-сквозь-Тьму, эрл-знаменосец → рикс септы |
| **Роль** | Враг-пленитель Сигурда (SK-03) → связан тайной Клятвой служить «небесному господину» (Белому Дьяволу) |
| **Книги** | SK-03, SK-06, SK-09; TB (Тени Пламени Подобного) |
| **Статус** | Жив; рикс Небесных Когтей, присягнул Пламени Подобному (SK-09) |

**Внешность:** высокий, гибкий копейщик-серебро, лицо изуродовано когтистой лапой, позже — отпечаток пылающей ладони Белого Дьявола (SK-03).
**Характер/речь:** горд, жаден до Славы, жесток, уважает силу; клянётся «Кровью Белого Дьявола». «Он дрался подобно Белому Дьяволу… и так и не дал мне победы» (SK-03).
**Биография.** SK-03: пленит и пытает Сигурда; побеждён голосом; посадил кукольника у винтокрыла. SK-06: новый рикс; выманивает Говорящую, свидетельствует; дарит Иллиумовый Страж-браслет, Сигурд возвращает ему тарн (гл. 17). SK-09: принимает Клятву Пламени Подобному, отпущен ждать знака (гл. 8).
**Связи:** мать — Видящая-сквозь-Тьму (рикс, духовидец; умерла по приказу «небесного господина» после закрытия Портала, SK-03, SK-06): «Лучше отдать мертвое железо, чем живую кровь»; старый товарищ Тростник-который-Поет убит голосом (SK-03).
