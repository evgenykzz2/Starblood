# Ассоль (Патриция Эванс)

| | |
|---|---|
| **Имена** | Позывной **Ассоль**; «в миру Патриция Эванс» (SK-07, гл. 3) |
| **Раса / фракция** | Землянка второго поколения, 25 лет, одна из первых рождённых землянами в Единстве; розовые пряди (SK-07) |
| **Роль** | Командир копья скаутов фригольда «Небо» |
| **Книги** | SK-01 (упом.), SK-04, SK-06, SK-07 (активно), SK-09–SK-11 |
| **Статус** | Жива; командир копья (SK-11) |

**Биография.**
- SK-01: упомянута среди копий фригольда.
- SK-04–05: «молодое крыло» (Ассоль, Фрост, Угрюмый, Уэнтвуд) — сторонники Марка.
- SK-06: отправлена защищать ферму Эйрика.
- SK-07: от зависти к дружбе: её копьё разгромлено Червями (Алекс убит Палачом, Морти выпит Вершителем), Сигурд её спасает; дарит ему бронзовую Руну «Сфера Тишины» (гл. 13; позже — Плащ Тишины, SK-08). Бронза, 7 циклов в Восхождении. Сигурд не может вспомнить, откуда её позывной (отсылка к «Алым парусам»).
- SK-10: приводит подкрепление в Либерти.
- SK-11: командир копья.

**Тайна:** детство одной из первых рождённых в Единстве (SK-07 §12).
