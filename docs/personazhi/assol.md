# Ассоль (Патриция Эванс)

| | |
|---|---|
| **Имена** | Позывной **Ассоль**; «в миру Патриция Эванс» (ЗК-7, гл. 3) |
| **Раса / фракция** | Землянка второго поколения, 25 лет, одна из первых рождённых землянами в Единстве; розовые пряди (ЗК-7) |
| **Роль** | Командир копья скаутов фригольда «Небо» |
| **Книги** | ЗК-1 (упом.), ЗК-4, ЗК-6, ЗК-7 (активно), ЗК-9–ЗК-11 |
| **Статус** | Жива; командир копья (ЗК-11) |

**Биография.**
- ЗК-1: упомянута среди копий фригольда.
- ЗК-4–05: «молодое крыло» (Ассоль, Фрост, Угрюмый, Уэнтвуд) — сторонники Марка.
- ЗК-6: отправлена защищать ферму Эйрика.
- ЗК-7: от зависти к дружбе: её копьё разгромлено Червями (Алекс убит Палачом, Морти выпит Вершителем), Сигурд её спасает; дарит ему бронзовую Руну «Сфера Тишины» (гл. 13; позже — Плащ Тишины, ЗК-8). Бронза, 7 циклов в Восхождении. Сигурд не может вспомнить, откуда её позывной (отсылка к «Алым парусам»).
- ЗК-10: приводит подкрепление в Либерти.
- ЗК-11: командир копья.

**Тайна:** детство одной из первых рождённых в Единстве (ЗК-7 §12).
