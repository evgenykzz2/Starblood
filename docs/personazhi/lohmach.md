# Лохмач (и «второй Лохмач»)

## Лохмач (первый)

| | |
|---|---|
| **Раса / Народ** | Абориген, мохнач («йети») — изгой из Людей Леса (ЗК-1) / «чужого Народа» (ЗК-2) |
| **Роль** | Следопыт копья Динамита |
| **Книги** | ЗК-1–ЗК-4 (упом. ЗК-5, ЗК-6, ЗК-9, ЗК-10) |
| **Статус** | Погиб в ЗК-4, закрыв Динамита от крыла Ястреба (статус уточнён в ЗК-5; ЗК-9, гл. 3: «погиб за колонию, спасая жизнь Динамиту») |

Понимает глобиш, говорит рычанием (ЗК-2); рыжий мех на лице (ЗК-5); принюхивается к новичку (ЗК-1); находит Хладноцветы и следы (ЗК-2). Встреча с Динамитом в Портале — Лохмач был целью задания (ЗК-2 §12). Его сородичи считают своими леса к востоку и северу (ЗК-6, гл. 1).

## «Второй Лохмач»

| | |
|---|---|
| **Кто** | Восходящий из Народа Леса (из похожего, но чужого Народа — по эмиссарам Иниэсс), пленник Азимандии с выжженной памятью |
| **Книги** | ЗК-8 («Йети Народа Леса», в карантине), ЗК-9, гл. 3 (вошёл во фригольд), ЗК-10 (серебро, подкрепление в Либерти) |
| **Статус** | Жив |

**Тайна:** родство с первым Лохмачом; его прошлое до плена.
