# Лохмач (и «второй Лохмач»)

## Лохмач (первый)

| | |
|---|---|
| **Раса / Народ** | Абориген, мохнач («йети») — изгой из Людей Леса (SK-01) / «чужого Народа» (SK-02) |
| **Роль** | Следопыт копья Динамита |
| **Книги** | SK-01–SK-04 (упом. SK-05, SK-06, SK-09, SK-10) |
| **Статус** | Погиб в SK-04, закрыв Динамита от крыла Ястреба (статус уточнён в SK-05; SK-09, гл. 3: «погиб за колонию, спасая жизнь Динамиту») |

Понимает глобиш, говорит рычанием (SK-02); рыжий мех на лице (SK-05); принюхивается к новичку (SK-01); находит Хладноцветы и следы (SK-02). Встреча с Динамитом в Портале — Лохмач был целью задания (SK-02 §12). Его сородичи считают своими леса к востоку и северу (SK-06, гл. 1).

## «Второй Лохмач»

| | |
|---|---|
| **Кто** | Восходящий из Народа Леса (из похожего, но чужого Народа — по эмиссарам Иниэсс), пленник Азимандии с выжженной памятью |
| **Книги** | SK-08 («Йети Народа Леса», в карантине), SK-09, гл. 3 (вошёл во фригольд), SK-10 (серебро, подкрепление в Либерти) |
| **Статус** | Жив |

**Тайна:** родство с первым Лохмачом; его прошлое до плена.
