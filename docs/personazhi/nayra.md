# Найра Эль-Кадис

| | |
|---|---|
| **Кто** | «Дочь Каравана», страж колёс, ходящая-в-тенях (тенеход-убийца) Великого Каравана |
| **Книги** | ЗК-10, ТБ-5 |
| **Статус** | Жива (Старый Заов — ЗК-10; Элтанир/Перекрёсток — ТБ-5) |

**Облик:** фиолетовая кожа, фиалковые глаза с золотыми искрами, короткие чёрные волосы, перечёркнутая звезда на шее, колечко в брови.
**Речь:** ментальная, мягкая («как кошачьей лапкой»); формулы Каравана: «Клянусь Дорогой», «это не пыль», «Странник отвернулся».
- «Я дам тебе золото, Восходящий. Свое. Без Клятвы. Без Монет. Сделай, что сможешь» (ЗК-10).
- «Дочь Каравана запомнит твои слова» (ЗК-10, финал).

**Биография:** спасла экипаж Сигурда, отдала своё золотое Развитие (→ Атрибут Искусность, ЗК-10, гл. 17), впервые летала; явно влюблена в Сигурда (Юки: «Одна женщина не обмануть другую»). ТБ-5: сводит Пламени Подобного с караваном Обочины, «тянется к Сигурду».
**Ранг:** серебро.
**Противоречие:** в ТБ-5 она «караванщица Эль-Керр»; в ЗК-10 Эль-Керр — род хранителя путей Вейна, а она — Эль-Кадис.
