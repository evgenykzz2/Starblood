# Найра Эль-Кадис

| | |
|---|---|
| **Кто** | «Дочь Каравана», страж колёс, ходящая-в-тенях (тенеход-убийца) Великого Каравана |
| **Книги** | SK-10, TB-05 |
| **Статус** | Жива (Старый Заов — SK-10; Элтанир/Перекрёсток — TB-05) |

**Облик:** фиолетовая кожа, фиалковые глаза с золотыми искрами, короткие чёрные волосы, перечёркнутая звезда на шее, колечко в брови.
**Речь:** ментальная, мягкая («как кошачьей лапкой»); формулы Каравана: «Клянусь Дорогой», «это не пыль», «Странник отвернулся».
- «Я дам тебе золото, Восходящий. Свое. Без Клятвы. Без Монет. Сделай, что сможешь» (SK-10).
- «Дочь Каравана запомнит твои слова» (SK-10, финал).

**Биография:** спасла экипаж Сигурда, отдала своё золотое Развитие (→ Атрибут Искусность, SK-10, гл. 17), впервые летала; явно влюблена в Сигурда (Юки: «Одна женщина не обмануть другую»). TB-05: сводит Пламени Подобного с караваном Обочины, «тянется к Сигурду».
**Ранг:** серебро.
**Противоречие:** в TB-05 она «караванщица Эль-Керр»; в SK-10 Эль-Керр — род хранителя путей Вейна, а она — Эль-Кадис.
