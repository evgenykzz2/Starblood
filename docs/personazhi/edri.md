# Эдри (Эд Ри Саттар, «Честный Странник»)

| | |
|---|---|
| **Кто** | Вольный торговец из Круга Ордал, род Великого Каравана; метаморф; «принадлежит Страннику» (ЗК-9) |
| **Книги** | ЗК-8, ЗК-9, ЗК-10, ЗК-11 |
| **Статус** | Жив; официальный посредник Неба в Либерти (ЗК-11) |

**Ранг:** серебро (Разум).
**Биография.**
- ЗК-8: пленник Азимандии, освобождён Сигурдом — должник, на карантине.
- ЗК-9: втирается в доверие; подозреваемый шпион.
- ЗК-10: принёс Клятву Небу («долг спасения»); советы о кайр’элиссах.
- ЗК-11: исчезает и возвращается (знает, что Сигурд «шагнул на золотой ранг», гл. 14); рунный бизнес с Сигурдом (+26 Монет за день, гл. 19); Сигурд ссужает ему 100 Монет под Клятву.
**Тайна:** на кого он работает — Странника (Хранителя) или Великих Караванов; связь с Найрой и Вейном Эль-Керром *(предположение)*.
