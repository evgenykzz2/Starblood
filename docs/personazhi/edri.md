# Эдри (Эд Ри Саттар, «Честный Странник»)

| | |
|---|---|
| **Кто** | Вольный торговец из Круга Ордал, род Великого Каравана; метаморф; «принадлежит Страннику» (SK-09) |
| **Книги** | SK-08, SK-09, SK-10, SK-11 |
| **Статус** | Жив; официальный посредник Неба в Либерти (SK-11) |

**Ранг:** серебро (Разум).
**Биография.**
- SK-08: пленник Азимандии, освобождён Сигурдом — должник, на карантине.
- SK-09: втирается в доверие; подозреваемый шпион.
- SK-10: принёс Клятву Небу («долг спасения»); советы о кайр’элиссах.
- SK-11: исчезает и возвращается (знает, что Сигурд «шагнул на золотой ранг», гл. 14); рунный бизнес с Сигурдом (+26 Монет за день, гл. 19); Сигурд ссужает ему 100 Монет под Клятву.
**Тайна:** на кого он работает — Странника (Хранителя) или Великих Караванов; связь с Найрой и Вейном Эль-Керром *(предположение)*.
