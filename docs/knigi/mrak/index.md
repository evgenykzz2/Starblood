# Мрак



*Фанфик-продолжение «Сына бури» по циклу Романа Прокофьева «Звездная Кровь». Дилогия о Марке, книга вторая*

!!! note "Статус"
    Написан целиком: пролог, 18 глав, 4 интерлюдии и эпилог. Выверен по памятке проверок: канон, связность, ошибки, манера автора, жесткость.

Во фригольде от его имени осталась половина. Мрак-подобный-Пламени стал просто Мраком — сыном героя, бронзовым лучником, мужем и отцом.

У Марка Кассиди Руна мертвой разведчицы, о которой знает только он, женщина, которая слышит за него, и мать, которая учит его брать. Старик, научивший его стрелять, знает слишком много. А над запретным Кругом горит капсула с чужаком, который заберет у него все по очереди.

Что остается от человека, у которого отняли Звездную Кровь?

Неофициальный фанфик-продолжение «Сына бури» по циклу «Звездная Кровь». Все права на мир и персонажей принадлежат Роману Прокофьеву.
