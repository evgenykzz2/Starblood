# 07. Словарь вселенной «Звездная Кровь»

> Единый алфавитный словарь терминов циклов «Звездная Кровь» (ЗК-1…ЗК-11, ЗК-12 — пролог и гл. 1–3) и «Тысяча Братьев» (ТБ-1…ТБ-5): статей — **580**, плюс отсылок «см.» для вариантов написания и синонимов — 152.

**Как читать:**
- **Значение** — итоговое (по последним книгам); если смысл менялся, это сказано в статье («ранее…/итог…»). *(предположение)* — догадка разборов или составителя.
- **Первое упоминание** — самая ранняя книга, где термин зафиксирован, с главой (по разборам; «интерлюдия», «пролог» — так в книге). Порядок книг для «ранее/позже» — по датам написания (приблизительно): ЗК-1…ЗК-6 → ТБ-1 → ЗК-7 → ЗК-8 → ТБ-2 → ЗК-9 → ТБ-3 → ЗК-10 → ТБ-4 → ЗК-11 → ТБ-5.
- **Где ещё** — другие книги, где термин появляется или раскрывается (по словарям разборов; список не исчерпывающий для сверхчастых слов вроде «Руна», «Восходящий»).
- Народы и фракции — кратко; подробно в статья «Народы и фракции». Места — кратко; география в статья «География». Персонажи сюда не входят (кроме божеств/Хранителей и прозвищ-терминов).
- Ругательства и присказки даны в кавычках «…» и указывают, **кто** их говорит.
